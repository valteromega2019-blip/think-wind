# Think Wind — apresentação pública

Página estática inspirada na identidade da apresentação do Think Monitor. A pasta contém somente HTML, CSS, o logotipo e uma ilustração conceitual feita em CSS, identificada como tal. Não inclui código do launcher nem instalador.

Publicação separada: `https://valteromega2019-blip.github.io/think-wind-site/`.

O aplicativo está em desenvolvimento Alfa, com código e instaladores públicos no repositório Think Wind. A página oferece download direto da 0.08 Alfa.

Não há dependências, scripts de build, coleta de dados ou JavaScript. GitHub Pages pode publicar estes arquivos diretamente da raiz do repositório público `think-wind-site`.
