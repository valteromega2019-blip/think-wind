IMPORTANTE · CONFIGURAÇÃO RECOMENDADA

As barras são configuradas durante a instalação.

O instalador da 0.19 Alfa · revisão 1 ativa Ocultar automaticamente a barra de tarefas no Windows e Usar somente a barra do Think Wind no launcher. As demais preferências são preservadas. Se a configuração automática falhar, o instalador informa como ajustar manualmente.

  1. Para conferir no Windows: Configurações da barra de tarefas → Comportamentos da barra de tarefas → Ocultar automaticamente a barra de tarefas.
  2. Para conferir no Think Wind: abra Personalizar → Sistema e verifique Usar somente a barra do Think Wind (ocultar a barra do Windows). Assim, o launcher mantém a barra original oculta enquanto estiver em uso.
  3. Para abrir junto com o computador: ainda em Personalizar → Sistema, ative Iniciar junto com o Windows.

Na 0.19 Alfa · revisão 1, a tecla Windows isolada abre o Iniciar do Think Wind enquanto o aplicativo está em execução. A interceptação usa uma thread dedicada e fica suspensa durante o Modo Jogo.

Você pode desativar a opção do launcher a qualquer momento. A ocultação automática escolhida no Windows continua sendo uma configuração do próprio sistema. Orientação oficial da Microsoft ↗

Requisitos e compatibilidade

Windows de 64 bits, com foco no Windows 11. Wi-Fi, brilho, mídia e bandeja dependem dos dispositivos, drivers, players e permissões do sistema.

Uma Alfa, com limites claros

A bandeja pode não mostrar ícones que o Explorer não disponibiliza. Troca de saída padrão usa uma interface interna do Windows, sujeita a mudanças. A consulta Bluetooth respondeu, mas não retornou dispositivos; descoberta real, pareamento e conexão não foram validados. A última correção do Iniciar ainda exige confirmação interativa. O instalador não tem assinatura digital.

0.19 ALFA · REVISÃO 1

O próximo passo
do seu desktop.

Arraste arquivos até o Dock e continue na janela do aplicativo. A interface usa permissões normais, com sensores em um coletor administrativo separado. A 0.19 traz widgets independentes, notas com exportação TXT, atalhos favoritos, fundo personalizável e prévia do Spotify com controles ao passar o mouse. A pesquisa destaca o primeiro resultado para abrir com Enter; sliders foram refinados e os indicadores agora são cápsulas claras sem contorno, usando a cor de destaque no aplicativo ativo.

Versão Alfa. Esta versão foi compilada sem executar testes automatizados ou type check separado, conforme a preferência do responsável pelo projeto. Precisão de sensores, latência e acabamento visual não foram medidos de forma independente nesta entrega. Consulte os limites e os avisos de segurança no GitHub.
